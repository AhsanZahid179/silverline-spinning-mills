# Silver Line Spinning Mills — Website

A multi-page business website built for **Silver Line Spinning Mills**, a textile spinning mill based in Lodhran, Pakistan (N5).

## 📋 Project Overview

This project is a responsive, animated business website consisting of four pages: Home, About, Products, and Contact. It was built as a static site using plain HTML, CSS, and JavaScript — no frameworks, no backend, no database — matching the scope of the assignment (a simple, professional business landing site).

## 🛠️ Tech Stack

- **HTML5** — page structure and content
- **CSS3** — custom design system (no framework), animations, responsive layout
- **Vanilla JavaScript** — sliders, scroll animations, mobile menu, contact form handling
- **Tabler Icons** (via CDN) — icon set used throughout the site

No build tools, package managers, or backend/database are used — the site runs entirely in the browser.

## 📄 Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Hero image slider, "Why Choose Us" section, Divisions showcase, testimonials slider |
| About | `about.html` | Company story, key stats, yarn production process timeline, mission & values |
| Products | `products.html` | Product categories (Combed, Carded, Blended, Open-End yarn), yarn count specification table, quality assurance section |
| Contact | `contact.html` | Business info cards, embedded Google Map, contact form with success confirmation |

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Custom logo integrated into the navigation bar
- Hero image slider with autoplay and manual controls
- Testimonials slider showcasing customer feedback
- Scroll-triggered reveal animations (fade, slide from left/right/up/down)
- Sticky navbar with scroll-based shadow
- Animated underline effect on navigation links
- Mobile hamburger menu with smooth transition
- Contact form with client-side validation, success message, and automatic reset (opens the visitor's email client via `mailto`)
- Embedded Google Map showing the mill's real location

## ℹ️ Data Sources

Some information on this site is **real and verified**, while other content is **placeholder data**, since Silver Line Spinning Mills does not currently have an official website or public product catalog.

**Real / verified (via Google Maps):**
- Business name and location (Lodhran, N5)
- Phone number
- Business hours
- Customer rating (4.0★) and one genuine customer review

**Placeholder / dummy content:**
- Company history and founding story
- Product names, descriptions, and yarn count specifications
- Mission, vision, and values statements
- Additional testimonials (beyond the one real review)
- Email address

This distinction is noted here so it's clear which content would need to be replaced with real business information before this site goes live for actual use.

## 🚀 How to View

No installation or build step is required.

1. Clone or download this repository
2. Open `index.html` in any modern web browser

Or, for the best experience with a local server (e.g. using VS Code's Live Server extension), open the project folder and start the server from `index.html`.
